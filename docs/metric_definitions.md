# Baseline V0 指标定义

## 使用原则

- Validation 用于模型与超参数选择。
- Test 仅在配置冻结后运行。
- 所有指标必须记录样本数、候选集构造方式、K 值和历史过滤规则。
- 不把离线回放结果描述成线上 A/B Test。

## 召回指标

### Recall@K

目标物品集合中被 Top-K 推荐命中的比例。当前 single-target 协议下等于是否命中的 0/1 均值。

### HitRate@K

至少命中一个目标物品的用户比例。Single-target 时与 Recall@K 相同，多目标时两者不同。

### NDCG@K

在命中的基础上给予靠前位置更高权重。Single-target 时，命中位置为 `rank` 的得分是 `1/log2(rank+1)`。

### MRR@K

首个相关结果排名倒数的均值；没有命中记为 0。

### Coverage@K

所有用户 Top-K 推荐中出现过的不同物品数，占可推荐物品总数的比例。

### Long-tail Recall@K

仅在长尾目标物品上计算 Recall@K。头部、腰部、长尾划分必须由训练期交互频次确定。

## 排序指标

### ROC-AUC

随机抽取一个正样本得分高于随机负样本的概率。适合整体区分能力，但不直接度量 Top-K 排序质量。

### PR-AUC

Precision-Recall 曲线面积。在正负样本不平衡时比 ROC-AUC 更敏感。

### LogLoss

二分类交叉熵，衡量概率预测质量。预测错误且过度自信会受到较大惩罚。

### GAUC

先在用户内部计算 AUC，再按有效样本数加权。用于降低不同用户样本混合导致的总体 AUC 偏差。

### Ranking NDCG@K

在同一用户候选集内按 DeepFM 分数排序，衡量正样本是否被排到更靠前位置。

### Calibration

比较预测概率与实际正例率。正式报告记录 Brier Score 或 Expected Calibration Error。

## 系统指标

- P50/P95/P99 推理延迟。
- 每秒请求数或候选打分吞吐量。
- 模型文件大小。
- 峰值 CPU/GPU 内存。
- 单 epoch 与总训练时间。

## 分层指标

至少按以下维度切片：

- 用户历史长度。
- 目标电影训练期热门度。
- 用户类型偏好熵。
- 冷启动/低活跃/高活跃用户。
- 头部/腰部/长尾物品。
